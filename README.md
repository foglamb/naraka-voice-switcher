# 永劫无间 · 语音切换助手 (NarakaVoiceTool)

面向普通玩家的《永劫无间》语音包切换工具：**中文界面不变，把角色配音换成日语/英语**，支持全量替换或按角色挑选。

## 特性

- **三步向导**：选游戏 exe → 选语言包目录 → 一键替换，无需命令行
- **按角色替换**：30 位角色芯片式勾选，想换谁语言点谁（例如：只让蓝梦说日语，其他角色保持中文）
- **语言参考包**：日语 / 英语
- **自动备份与恢复**：首次替换为每个中文语音文件生成独立 `.bak`，可一键恢复；已有备份不会被自动覆盖
- **安全防呆**：游戏运行中自动拒绝操作；备份永不被工具生成的语言包覆盖；失败时弹窗可复制报错并落盘日志
- **免安装**：单文件 exe，双击即可食用

## 使用步骤

### 第一步 · 设置路径
- **游戏 exe**：选择 `NarakaBladepoint.exe`，兼容 Steam 根目录与官方启动器的 `program` 目录。自动识别旧版 `ChineseCN.pck`，以及新版 `ChineseCN_Common.pck`、`ChineseCN_Ingame.pck`、`ChineseCN_Outgame.pck` 三分包。
- **语言包目录**：选择已解压、与当前游戏版本及分包布局匹配的日语或英语语音资源。
  - 单包版：中文 `ChineseCN.pck` 对应 `Japanese.pck` 或 `English.pck`。
  - 三分包版：目标语言必须具备 `_Common.pck`、`_Ingame.pck`、`_Outgame.pck` 三个同语言文件；例如 `JapaneseJP_Common.pck`、`JapaneseJP_Ingame.pck`、`JapaneseJP_Outgame.pck`。支持 `Japanese`/`JapaneseJP`、`English`/`EnglishUS` 文件名前缀。
  - 一个语言作为一组选取，可搜索解压目录的子目录；音乐、音效和 `Init.pck` 不作为参考语音。
  - 只有中文资源、缺少目标语言或分包不齐时，「开始替换」保持禁用。工具和 Release 均不附带游戏语音。

### 第二步 · 替换语音包
- **全量替换**：全部角色与系统语音换成所选语言（等价官方完整语言切换）
- **按角色替换**：勾选想换的角色（可多选，「全选」可切换），其余保持中文
- 自动备份中文原声

### 第三步 · 恢复原版
- 一键恢复全中文语音

## 已知限制

- 游戏更新后需使用同版本的目标语言资源；如当前文件与已有备份不同且不符合工具部署标记，工具会保留原备份并停止操作。确认游戏文件完整后，将旧 `.bak` 另存到其他目录，再重新备份与替换。
- 口型动画按中文音节制作，替换后口型不完全对齐，属正常现象
- 泰语语言包的角色配音实为英语兜底（官方未制作泰语角色配音），换泰语 ≈ 换英语
- 新角色：当前版本已上线的角色语音已全部收录；后续新英雄需在 `src/roles.cpp` 角色表登记内部英文名（如 `lyam`/`kylin`）后重新编译，界面芯片与布局自动扩展
- 「恢复原版」依赖每个中文文件旁的 `.bak` 备份及 `.nvt` 部署标记；请保留这些文件。缺失、损坏或游戏已更新而无法确认状态时，请用游戏平台的文件完整性校验恢复。

## 构建

VS MSVC 环境，C++17。仓库的 Windows Release 工作流会运行目录识别回归、使用生成的有效 AKPK 文件验证实际替换/恢复函数，并启动发布 EXE 检查 GUI 的三分包识别状态；全部通过后才创建 Release。

这些自动检查不包含用户实际游戏安装中的语音播放验证。文件能定位不代表内部格式一定兼容；替换前会校验中文、目标及重建文件，不兼容时停止并显示具体原因。
